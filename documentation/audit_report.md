# Repository Audit: Canadian Household Credit and Interest-Rate Analysis

**Audit date:** 2026-10-18  
**Scope:** Review of the selected raw snapshots, processed data, headline README claims, research memo and outputs, ingestion/transformation/analytics code, SQL views, freshness and validation artifacts, dashboard, and tests. No source modules or research datasets were intentionally changed; running tests may refresh local bytecode caches. The only intentional workspace edit is this report.

## Executive Conclusion

The headline regime averages and the CA$7.046 billion +100 bp consumer-credit sensitivity reproduce exactly from the selected raw Bank of Canada snapshots. The 20-series / 12,049-observation count also reconciles to raw source totals. These figures need interpretation qualifications: regimes use the same reference month's average policy rate while observations are stamped on the first of that month, and the sensitivity assumes the whole chartered-bank consumer-credit balance reprices immediately for a full year.

The freshness status in the checked-in report is accurate only as of its 2026-10-13 processing time. Under the repository's own schedule, five daily/weekly series are past their grace dates on the audit date, 2026-10-18. The repository also contains an obsolete completion summary that still calls the September snapshot current. Tests and all nine DuckDB views passed; the complete output-writing pipeline and PostgreSQL integration were not rerun.

## Data and Transformation Review

- Raw selected source totals reconcile to the processed fact table: 11,465 Bank observations and 584 Statistics Canada observations. Every selected series has a continuous declared monthly, quarterly, or weekly date sequence according to the configured cadence checks; business-daily dates naturally omit weekends and holidays.
- The configured BoC units distinguish rates (`percent`) and balances (`millions_cad`). Statistics Canada quarterly debt-to-income is a ratio; the three level series are configured as `millions_cad`. Source unit/scalar metadata is not carried through the raw observation schema.
- The transformation rejects duplicate keys, malformed dates/numbers, future dates, missing series metadata, and incomplete manifests. It preserves source null values in the fact table. However, the Python metrics and research loaders drop null-valued rows before calculating previous-observation changes. If future source data contain suppressed null rows, those calculations could bridge across the missing point; that does not affect this selected snapshot, which has zero nulls.
- `vw_yoy_change` uses an exact one-year date join, and research YoY uses the corresponding exact-date rule. No interpolation or forward-fill is used for rate comparisons.
- Snapshot comparisons found no changed overlapping values in the two adjacent snapshot pairs described above. No comprehensive revision history or vintage comparison report exists.

## Reproduction and Checks

- `python -m pytest -q`: **18 passed, 4 subtests passed**.
- Independent raw-CSV recomputation: all three regime means/sample sizes and the CA$7,045.82 million +100 bp sensitivity reproduced.
- `python -m python.db.duckdb_runner`: succeeded; all nine views created and queried.
- The full offline pipeline was not rerun because its documented commands overwrite processed and research outputs. Live ingestion was not rerun. PostgreSQL and a clean dependency installation were not tested.

## Overall Assessment

The principal arithmetic is reproducible and the current raw/processed row counts reconcile. The two presentation risks needing correction before the regime figures are described as point-in-time analysis are (1) the same-month policy-rate input paired with first-of-month labels and (2) freshness being described without its 2026-10-13 as-of timestamp. The sensitivity is arithmetically correct only as a full, immediate repricing scenario. Historical provider revisions and future Statistics Canada scalar changes are not controlled by the current audit pipeline.
